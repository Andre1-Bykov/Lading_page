# Guitar Shop

Статический лендинг магазина акустических гитар. Сайт написан на HTML, CSS и JavaScript и не требует сборки или установки зависимостей.

## Структура проекта

```text
.
├── assets/
│   └── images/       # Локальные изображения сайта
├── css/
│   └── style.css     # Стили страниц
├── js/
│   └── script.js     # Слайдер и таймер акции
├── .vscode/          # Настройки Visual Studio Code
├── index.html        # Главная страница
└── README.md
```

## Запуск

Откройте `index.html` в браузере. Для локального сервера можно открыть проект в Visual Studio Code и запустить Live Server.

## Возможности

- Адаптируемые секции с информацией о магазине, процессом заказа и портфолио.
- Слайдер изображений с кнопками, точками и автоматическим переключением.
- Таймер обратного отсчёта акции.
- Форма заявки на заказ.

Некоторые фотографии в карточках и портфолио загружаются с Unsplash, поэтому для их отображения требуется подключение к интернету.
